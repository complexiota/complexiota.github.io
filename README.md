## 🌌 Website Architecture & Theme

This website is custom-built from the ground up utilizing purely **HTML5, CSS3, and Vanilla JavaScript** to ensure maximum performance without relying on heavy frameworks.

### Deep Tech Aesthetic
The visual language of the site is designed to reflect an AI/ML workspace:
- **Deep Space Dark Mode**: An immersive dark navy/slate background.
- **Glassmorphism**: Semi-transparent, blur-backed project cards with 3D tilt interactions on hover.
- **Neon Accents**: "Neon Cyan" and "Electric Purple" gradients.
- **Particle Network**: A custom HTML5 Canvas background drawing a dynamic, interactive neural network that reacts to the mouse cursor.

### Seamless Contact
Integrated with the **Web3Forms API** to handle contact requests completely client-side without relying on generic `mailto:` links, providing a smooth user experience.

## 🛠️ Local Development

If you'd like to run this site locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/complexiota/complexiota.github.io.git
   cd complexiota.github.io
   ```
2. **Launch a local server**:
   ```bash
   python -m http.server 8000
   ```
3. **View**: Open `http://localhost:8000` in your web browser.
